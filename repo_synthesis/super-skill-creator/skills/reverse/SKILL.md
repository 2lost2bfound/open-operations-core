# /reverse — Reverse-Engineer a Website into a Skill

> This skill is platform-agnostic. It works with any AI agent
> that supports Markdown skill files (Claude Code, Codex,
> OpenCode, Cursor, Windsurf, Cline, Aider, or custom agents).

## Constitution Compliance

This skill follows the super-repo constitution rules:

- **Frontmatter**: Every note and output gets frontmatter (repo, url, floor, status, added, overlaps-with, feeds-into).
- **Append-only**: Never delete another agent's log entries.
- **One task, one owner**: If no clear owner, flag for the human.
- **Escalate ambiguity**: Use `## Open Questions` rather than silently assuming.
- **Pre-flight**: Check INDEX.md `last-scanned` before big projects.

## When to Use

- User types `/reverse <url>`
- User says "reverse engineer this site"
- User wants to turn a documentation website into an agent skill
- User wants to create a skill from an existing tool's docs

## Workflow

1. **Crawl** — Run `ssg reverse <url>` to crawl the target website (depth=2 by default).
2. **Analyze** — The crawler extracts content, metadata, and structure from each page.
3. **Generate** — The 5-phase pipeline (Discovery → Design → Architecture → Detection → Implementation) creates a complete skill directory with SKILL.md, workflow references, and scripts.
4. **Validate** — Quality gates check frontmatter completeness, name/description length, and file size limits.
5. **Install** — Optionally install to one or more agent platforms.

## Usage

```bash
# Basic usage
ssg reverse https://docs.example.com

# With custom name and depth
ssg reverse https://docs.example.com --name my-skill --depth 3

# Auto-install to specific platforms
ssg reverse https://docs.example.com --install-to claude-code --install-to opencode

# Full options
ssg reverse <url> [--name NAME] [--output DIR] [--depth N] [--install-to PLATFORM]
```

## Inputs

- **url** (required): The website URL to reverse-engineer
- **name** (optional): Override the auto-generated skill name
- **output** (optional): Output directory (default: `./skills/`)
- **depth** (optional): Crawl depth, default 2
- **install-to** (optional): Platform(s) to auto-install to

## Outputs

- **Skill directory**: Contains SKILL.md, references/workflow.md, scripts/main.py
- **SKILL.md**: Constitution-compliant frontmatter (repo, url, floor, status, added, overlaps-with, feeds-into), platform-agnostic body
- **Validation report**: Pass/fail summary

## Generated Skill Format

Every skill generated by `/reverse` includes:

1. **Constitution-compliant frontmatter** — repo, url, floor, status, added, overlaps-with, feeds-into
2. **Platform-agnostic body** — no platform-specific language, works on any agent
3. **Open Questions section** — for escalating ambiguity per constitution rules
4. **Workflow references** — detailed step-by-step in `references/workflow.md`
5. **Executable script** — `scripts/main.py` as entry point
