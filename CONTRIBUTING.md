# Contributing

Small, focused pull requests are welcome.

Before opening a pull request:

1. Run `./scripts/secret-scan.sh`.
2. Run the Python import and intake checks from the README.
3. Explain the behavior change and its safety boundary.
4. Use placeholders in fixtures and screenshots.

Never include API keys, cookies, private endpoints, personal documents,
customer data, or local runtime directories in an issue, fixture, screenshot,
commit, or pull request.
